# Doktoreltern v2: planning

Planning for a complete rewrite and redesign of Doktoreltern. This folder began on 2026-10-06 as
`successor-plan/` in the werkbank repository (a successor to werkbank, working name "Leitstand")
and was moved here the same day, at werkbank commit e5f0c72. Its git history up to the move is in
werkbank.

Read in this order:

1. `V2-SYNTHESIS.md`: where the thinking stands now. Start here.
2. `MODULARITY.md`: the module cut the synthesis builds on.
3. `BRIEF.md`: Robin's original brief and interview answers.
4. `SCOPING-DRAFT.md`: the first draft ("Leitstand"), as the first panel reviewed it. Superseded
   by the synthesis, kept as the record. `redraft/` holds two sections rewritten after that panel.
5. `reviews/`: the first panel's seven reviews and their consolidation (`reviews/SYNTHESIS.md`);
   `reviews/round-2/` holds the second panel.
6. `research/`: surveys and spikes.

Paths in the older documents:

- `successor-plan/...` means this folder.
- Paths such as `V8.3-SCOPING.md`, `DECISION-LOG.md`, `CHANGELOG.md`, `v8.3-plan/...` and
  `v8.4-plan/...` are in the werkbank repository (`../../werkbank/` from here).
- "Doktoreltern" in the older documents means version 1: everything in this repository outside
  this folder.

Not committed: reviewers' scratch folders, spike run logs, and `research/spike-reset/logs.tar.gz`
(it contains an email address).
